# EPL | Energy and Propulsion Lab

A production-ready placeholder website for **EPL, Energy and Propulsion Lab**. The project is built with Vite, React, TypeScript, and custom CSS for a clean university research laboratory aesthetic.

## Features

- Sticky shrinking navigation with desktop and mobile menus
- Full-viewport hero with placeholder image, overlay, CTAs, and scroll cue
- About section with animated counters
- Research, publications, projects, news, members, gallery, contact, and footer sections
- Responsive masonry gallery with lightbox
- Backend-ready contact form structure
- Accessible semantic markup, focus states, alt text, and reduced-motion support
- Centralized placeholder content in `src/data/content.ts`

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run start
```

## Replacing Placeholder Content

Most content lives in `src/data/content.ts`. Replace placeholder names, dates, emails, project details, publication details, and image URLs there.

The hero image and contact image are defined in `src/App.tsx`. All images use replaceable placeholder URLs.

## Deployment

The `dist` folder generated by `npm run build` can be deployed to static hosting providers such as Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any server that can serve static files.

For Vercel or Netlify, use:

- Build command: `npm run build`
- Output directory: `dist`
